Run details

We choose the best all-round agent by its weakest task area first. Different benchmarks use different scoring rules; the displayed scores are normalized percentages. They are accuracy percentages only for pass/fail metrics. Native metrics are retained in the exported results table.

Some new versions stop after a quick check. Only versions that finish the full test appear in the comparison charts.

The first run changes the agent’s shared instructions. Its model, tools and task limits stay fixed.

Finance and math tasks mostly pass or fail. Legal tasks also earn credit for individual rubric items.
